# Telegram MCP for Umbrel

This is a community-store package for [nguyenvanduocit/telegram-mcp](https://github.com/nguyenvanduocit/telegram-mcp) at pinned upstream commit `b57f47d93ed1d3e05fe615db5640a05740aea043`; see `image/UPSTREAM.md` for modifications and provenance.

- The app has an owner-only setup UI and a separate bearer-authenticated Streamable HTTP `/mcp` endpoint. The Telegram API credentials, verification code, 2FA and session are not to be sent in chat; enter them through the app's private browser setup.
- The MCP bearer token gives the connected agent account-level Telegram capabilities, including sending, editing, deleting and admin tools. Grant it only to a trusted agent, and require an explicit user instruction before account mutations.
- The token is derived by Umbrel in `exports.sh` and injected as `TELEGRAM_MCP_TOKEN` into the server, never committed or printed by the build. To connect Hermes after the app is running, retrieve the token *privately* via the umbrelOS app terminal (Settings → Advanced Settings → Terminal → App → Telegram MCP; `printenv TELEGRAM_MCP_TOKEN`) and enter it into the `hermes mcp add telegram --url http://nickseagull-telegram-mcp_server_1:8080/mcp --auth header` prompt in the Hermes app terminal. Do **not** paste it into Matrix, PR comments, shell history or logs. The wizard stores the secret under Hermes's private `.env` and a reference in config. Test with `hermes mcp test telegram` after login; tool discovery may require a new Hermes session.
- `/data` holds credentials and session. `/media` is the separate movable download/upload directory. `telegram_send_media` accepts only direct regular files within `/media` and will not follow symlinks outside it. `telegram_download_media` writes exclusive filenames to `/media`, never to an arbitrary `download_dir`; retries on an existing filename fail rather than overwrite. It is not a read-only tool.

Image release: the workflow publishes an amd64/arm64 index. Pin the *index digest* in `docker-compose.yml` and verify the publicly pullable manifest before merging. The app has not been live-logged into Telegram in CI; perform an owner setup and session-resumption check on an installed Umbrel app before claiming live Telegram connectivity.
